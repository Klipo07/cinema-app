# Cinema App — веб-приложение «Кинотеатр»

Fullstack веб-приложение для управления кинотеатром. Клиент-серверная архитектура с использованием трёх баз данных: PostgreSQL (реляционные данные), MongoDB (документы) и Redis (кэширование). Развёртывание через Docker Compose.

## Возможности

- Просмотр расписания фильмов и сеансов
- Управление залами, фильмами и сеансами
- Хранение структурированных данных в PostgreSQL (таблицы в 3НФ, связи через внешние ключи)
- Хранение документов в MongoDB (коллекции с агрегацией)
- Кэширование часто запрашиваемых данных в Redis (с поддержкой TTL)
- Запросы с JOIN и GROUP BY к PostgreSQL
- Агрегационные пайплайны MongoDB
- Docker Compose для запуска всей инфраструктуры одной командой

## Стек технологий

| Технология | Роль |
|---|---|
| **Node.js + Express** | Backend-сервер, REST API |
| **PostgreSQL** | Реляционная БД (фильмы, залы, сеансы) |
| **MongoDB** | Документная БД (коллекции предметной области) |
| **Redis** | Кэш-хранилище с TTL |
| **HTML / CSS / JS** | Клиентская часть (статические страницы) |
| **Docker Compose** | Оркестрация контейнеров (PostgreSQL, MongoDB, Redis) |

## Быстрый старт

**Требования:** Docker и Docker Compose

```bash
# Клонировать репозиторий
git clone https://github.com/Klipo07/cinema-app.git
cd cinema-app

# Запустить БД через Docker Compose
docker-compose up -d

# Установить зависимости
npm install

# Инициализировать базы данных
npm run init-db

# Запустить сервер
npm start
```

Приложение будет доступно по адресу `http://localhost:3000` (или порт, указанный в конфигурации).

## Базы данных

**PostgreSQL** — минимум 3 таблицы в 3НФ с первичными и внешними ключами. Запросы используют JOIN для связи таблиц и GROUP BY для агрегации данных.

**MongoDB** — минимум 2 коллекции с документами предметной области. Используются агрегационные пайплайны для аналитических запросов.

**Redis** — кэш-хранилище с минимум 2 ключами. Данные загружаются из PostgreSQL/MongoDB и хранятся с установленным TTL для автоматической инвалидации.

## API

Серверная часть реализует REST API для взаимодействия клиента с базами данных. Все маршруты описаны в `server.js`.
